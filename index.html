How it works

Three steps, no typing IP addresses.

01

Scan the code

Launch the desktop receiver — it shows a QR code and pairing PIN immediately. Scan it from the phone app, or type the three fields by hand.

02

Pick a scenario

Speaker nearby, distant voice, or music — each tunes gain and noise suppression for that situation.

03

Go live

Tap Start. The desktop app plays your phone's mic into a virtual audio cable, so Discord, your game, or any app sees it as a real microphone.

Features

Built for real-time voice, not file transfer.

QR + PIN pairing

Pair by camera scan or manual entry. A rotating PIN means only devices you've actually paired can stream to your desktop.

Sub-frame latency

Raw PCM over UDP in 10ms chunks. A dropped frame is inaudible; waiting for a retransmit isn't — so we don't wait.

Connection quality

Live Excellent/Good/Poor/Lost feedback on the phone, driven by real packet-loss stats from the desktop side.

Noise suppression

Platform noise suppression, AGC, and echo cancellation applied per scenario — skipped automatically for the Music preset so it doesn't get mangled.

Jitter buffer + concealment

Out-of-order packets get reordered; a real gap is concealed instead of playing back as a click or glitch.

No cloud, no account

Everything runs over your own WiFi. No signup, no relay server, no data leaving your network.

Why local-only

Your voice never leaves your network.

Most "phone as mic" apps either need an account or route audio through a third-party relay. Phone Mic doesn't — the phone talks directly to your PC over WiFi, and that's the whole path.

  • No servers. Pairing, audio, and quality feedback all stay on your LAN.
  • No account. Install and go — nothing to sign up for.
  • Open source. Every line of the pairing and audio pipeline is public — read it, fork it, send a PR.

One-time setup

Install a virtual audio cable first.

Phone Mic needs somewhere on the desktop to hand off the audio stream as a real microphone input. That's what a virtual audio cable does — install one before you run the desktop receiver. Free, one download, no account.

Windows — VB-Audio Virtual Cable

The page also lists paid A+B / C+D bundles — you only need the plain one below.

Download: "VB-CABLE Driver" zip (not A+B / C+D)
  1. On the page below, download the plain VB-CABLE Driver zip (skip the A+B / C+D bundles).
  2. Extract it, right-click VBCABLE_Setup_x64.exe, run as administrator.
  3. Reboot if Windows asks you to.
Download directly

macOS — BlackHole

Installed via Homebrew — there's also a 16ch/64ch version, you want 2ch.

brew install blackhole-2ch
  1. Install Homebrew first if you don't have it: brew.sh.
  2. In Terminal, run brew install blackhole-2ch — specifically 2ch, not 16ch/64ch.
  3. If apps don't see it right away, log out and back in (or restart).

No Homebrew and don't want to install it? BlackHole's GitHub releases also has a manual installer.
